# 影响分析流程

## 核心原则

影响 = 传导路径，不是名词罗列。每条影响必须回答"通过什么机制传导到谁"。

## 步骤

1. **确认事件**：用 1 句话复述待分析的事件，确保与用户所指一致。
2. **检索证据**：分别检索——事件本身、受影响方、历史类似事件（"历史"检索词对校准判断很关键）。
3. **画传导链**：按"事件 → 直接影响 → 二阶影响"展开，每环注明：
   - 事实（有库内证据支撑，标引用 [n]）
   - 推测（无直接证据，标注"推测"并说明推理依据）
4. **给对立面**：至少给出 1 条反方观点或失效条件（什么情况下这个影响不会发生）。避免单边叙事。
5. **输出结构**：
   - 事件一句话
   - 传导链（事实/推测分开标注）
   - 反方观点或失效条件
   - 置信度自评（高/中/低 + 一句理由）

## 禁止

- 无证据的数字预测（价格目标、涨跌幅）
- 把相关性说成因果性
