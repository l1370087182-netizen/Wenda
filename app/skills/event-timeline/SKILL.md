# 事件时间线追踪流程

## 步骤

1. **锚定事件**：从用户问题中提取事件主体（人物/公司/国家/技术名）。若模糊，先列出 2-3 个候选主体请用户确认，不要自行猜测。
2. **多轮检索**：用以下检索词组合搜索（每轮都做）：
   - 事件主体 + 最早相关时间词（如"开始""首例""首次"）
   - 事件主体 + 进展词（如"升级""回应""后续"）
   - 事件主体单独检索（兜底）
3. **排序去重**：按 published_at 排序；同一天多篇取重要度最高的一篇。
4. **输出时间线**（固定格式）：
   - **<日期1>**：<发生了什么>（来源 [n]）
   - **<日期2>**：<新进展>（来源 [n]）
   - **当前态势**：1-2 句最新状态
5. **诚实原则**：库里证据不足时明确说"检索窗口内仅找到 X 天的记录"，不要脑补中间环节。

## 输出格式

Markdown 时间线列表，末尾附完整来源列表。
