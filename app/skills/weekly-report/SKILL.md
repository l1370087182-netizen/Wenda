# 深度周报生成流程

## 输入

研究 Agent 检索到的本周文章（建议检索词：本周各分类热点、交叉洞察相关主题）。

## 步骤

1. **聚类主线**：把相关文章按事件归组。判定标准——同一事件/同一趋势的文章为一组；只出现一次的孤立文章不进主线。
2. **筛选主线**：最多保留 3 条，按"跨天数 + 相关文章数"排序。跨天持续发酵的事件优先。
3. **撰写结构**（固定）：
   - **本周主线**（每条 100 字内：事件概括 + 演进过程 + 影响，附 ≥2 篇不同日期的证据文章引用 [n]）
   - **各分类要点**（六类各 1-2 句，只挑最重要的）
   - **下周关注**（基于本周趋势的 1-3 个预判，明确标注这是推测）
4. **篇幅**：全文 800 字内。禁止套话（"综上所述""值得关注的是"开头除外，不得作为填充）。

## 输出格式

Markdown，一级标题为"深度周报 · <起止日期>"，引用编号 [n] 对应来源列表。
